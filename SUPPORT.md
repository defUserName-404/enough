# Getting help

- **Questions / how do I…?** Use [Discussions](../../discussions).
- **Something broken?** [Open a bug report](../../issues/new?template=bug_report.yml).
- **Idea?** [Open a feature request](../../issues/new?template=feature_request.yml).
- **Security issue?** See [SECURITY.md](SECURITY.md). Do not file it publicly.

Read the [README](README.md) and [`docs/`](docs) first; many setup questions
(Device Owner provisioning, Xiaomi/HyperOS steps) are covered there.
